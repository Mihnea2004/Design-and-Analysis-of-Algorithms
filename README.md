Design and Analysis of Algorithms – Coursework

This repository contains my work from the Design and Analysis of Algorithms course, focused on deepening the understanding of trees and graphs — core data structures with broad practical applications.

All implementations are written in C, allowing fine-grained control and detailed analysis of how each data structure and algorithm works.

Note: Both the code and theoretical explanations are in Romanian, but the logic and structure of the algorithms are easy to follow regardless of language.
